# План разработки VetCare Mobile

Актуальный `codex.md` описывает Flutter frontend. Предыдущий backend-план сохранён в [docs/backend-plan.md](docs/backend-plan.md). Express backend остаётся в `src/`.

Выбраны Flutter/Dart, Provider + ChangeNotifier, Dio и Flutter ScreenUtil. Axios относится к JavaScript; для Dart используется Dio. Подробные API-контракты, макеты и правила записи документом не заданы.

## Ближайший шаг и ограничения

В текущем окружении Flutter/Dart SDK не найдены. Исходники первого этапа созданы вручную; платформенные проекты отсутствуют, Flutter-тесты не запускались. Инструкции генерации, запуска и проверки: [docs/mobile.md](docs/mobile.md).

Backend сейчас предоставляет только health endpoints. Контракт списка питомцев в документации — предложение для следующей интеграции. Вход, запись к врачу и медицинская история пока не реализованы.
